## 📌 О проекте

**AI_Trader** — это объединённая торговая платформа, созданная на базе трёх предыдущих проектов:
- `ai-trader-mt5_0.1.1` — подключение к MetaTrader 5 и риск-менеджмент
- `AI_TRADER_0.0.1.2` — прототип алгоритмического инструмента
- `pattern_recognition_engine` — движок распознавания торговых паттернов

---

## 🚀 Возможности

- **Распознавание паттернов**: свечные, геометрические и гармонические паттерны
- **Технический анализ**: 20+ индикаторов (RSI, MACD, Bollinger Bands и др.)
- **Машинное обучение**: классификация и кластеризация паттернов
- **Бэктестинг**: полная система тестирования стратегий
- **Интеграция с MT5**: автоматическое исполнение ордеров
- **GUI**: удобный графический интерфейс управления
- **Демо-режим**: безопасное тестирование на демо-счёте

---

##  Технологии

- Python 3.10+
- MetaTrader 5
- Poetry (управление зависимостями)
- scikit-learn, pandas, numpy
- Plotly, Matplotlib

## ⚙️ Установка

```bash
git clone https://github.com/DiamondDim/AI_Trader.git
cd AI_Trader
poetry install
```
