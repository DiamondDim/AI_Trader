## 📊 ТЕКУЩЕЕ СОСТОЯНИЕ СТРАТЕГИИ

### Свинг-стратегия (H1 таймфрейм)
**Компоненты:**
1. **Паттерны:** Bullish Engulfing, Bearish Engulfing, Doji, Hammer
2. **Индикаторы:**
   - EMA 50 (тренд)
   - ATR 14 (волатильность для SL/TP)
   - Stochastic 14,3,3 (перекупленность/перепроданность)
   - ADX 14 (сила тренда)

**Фильтры сигналов:**
- Фильтр 1: Тренд (EMA 50) - цена должна быть выше EMA для бычьих, ниже для медвежьих
- Фильтр 2: ADX > 20 (сильный тренд)
- Фильтр 3: Stochastic - для бычьих < 30, для медвежьих > 70
- Фильтр 4: Активная сессия (10:00-23:00 МСК)

**Risk Management:**
- Динамический расчет лота на основе 1% риска от депозита
- Формула: `lot = (balance × 0.01) / (sl_distance_points × point_value_rub)`
- Проверка минимального лота брокера (volume_min = 0.01)
- Если расчетный лот < минимального → сделка пропускается

**SL/TP на основе ATR:**
- Stop Loss: ATR × 1.5
- Take Profit: ATR × 3.0 (соотношение R:R = 1:2)

## 🔧 ТЕКУЩИЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: JPY-пары требуют огромный депозит
**Причина:** На H1 ATR = 1000-5000 пунктов, стоимость пункта высокая
**Решение:** Создать интрадей-стратегию на M15 (ATR в 3-4 раза меньше)

### Проблема 2: RUB-пары показывают нереальные убытки
**Причина:** Неправильный расчет PnL в рублях
**Решение:** Исправить формулу конвертации в `backtesting.py`

### Проблема 3: Блокировка сервисов в РФ
**Статус:** GitHub может быть заблокирован
**Решение:** 
- Установлен Browsec VPN для браузера
- Альтернатива: GitLab.com (не заблокирован)
- Настройка git через прокси: `git config --global http.https://github.com.proxy`

## 💾 КЛЮЧЕВЫЕ ФАЙЛЫ КОДА

### 1. `core/backtesting.py` - Движок бэктестинга
**Основные методы:**
- `_calculate_sl_tp_atr()` - расчет SL/TP на основе ATR
- `_calculate_dynamic_lot()` - динамический расчет лота
- `_calculate_point_value_rub()` - стоимость пункта в рублях
- `run()` - прогон сигналов с расчетом PnL

**Ключевые параметры:**
```python
risk_per_trade = 0.01  # 1% риска
atr_sl_multiplier = 1.5  # SL = ATR × 1.5
atr_tp_multiplier = 3.0  # TP = ATR × 3.0
```

### 2. `strategy_swing/test_swing.py` - Тестовый скрипт
**Поддерживает:**
- Аргументы командной строки: `python test_swing.py EURUSDrfd`
- Динамический лот
- Вывод статистики: винрейт, PF, просадка, пропущенные сделки

### 3. `broker/mt5_connector.py` - Коннектор к MT5
**Основные методы:**
- `connect()` - подключение к терминалу
- `get_rates()` - получение исторических данных
- `get_symbol_info()` - информация о символе (point, digits, volume_min)
- `place_order()` - открытие ордера (в демо-режиме)

### 4. `list_symbols.py` - Интерактивный выбор пар
**Функции:**
- `get_available_symbols()` - получение списка пар из MT5
- `select_symbols()` - интерактивный выбор (номера, диапазоны)
- `run_tests()` - запуск тестирования для выбранных пар
